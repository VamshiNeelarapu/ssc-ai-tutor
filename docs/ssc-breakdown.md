# SSC CGL 2027 — Master Syllabus Breakdown & Practice Tracker

**Status:** Provisional planning baseline for SSC CGL 2027  
**Prepared:** 21 October 2026  
**Authority rule:** The SSC CGL 2027 notification, when published, overrides this document. Until then, use the latest verifiable official SSC CGL notification as a baseline, not a guarantee that all 2027 rules will remain unchanged.

## How to use this file

This document is a topic checklist, practice tracker, PYQ map and revision planner. The detailed subtopics expand broad official syllabus headings into study tasks; not every subtopic below is separately named in the notification.
**Status codes:** `NS` Not started · `L` Learning · `P` Practising · `R` Revision due · `C` Completed to standard · `W` Weak.
**Suggested completion standard:** Understand the concept, solve representative questions, review errors, and revisit in spaced revision. Watching a lecture alone is not completion.
**Labels used:**

- **Official scope:** Broad syllabus areas described by SSC.
- **Expanded topic:** A practical breakdown under an official heading.
- **Supplementary practice:** Useful adjacent drills; not a claim that SSC explicitly lists that exact label.
- **PYQ-derived priority:** A study-planning judgement, not a prediction of future questions.
  Suggested tracker fields: `Topic ID | Topic | Status | Questions attempted | Correct | Accuracy | Median time | Error type | PYQ year | Revision dates | Mock evidence | Notes`.
  Error types: `CONCEPT`, `METHOD`, `CALCULATION`, `MISREAD`, `TIME`, `GUESS`, `MEMORY`, `CARELESS`.
